L'objectif de la tache est de fusionner les deux menu "menu" et "connexion".

Le  nouveau menu est positionné en haut à gauche de l'écran, et affiche par défaut "Menu" ou l'icone de menu en mode smartphone.
Le  menu contient les entrées des deux menu existant Trié par ordre alphabétique.
Une fois l'utilisateur connecté, le nom de l'utilisateur est affiché non plus dans le menu, mais dans le header de la page en haut à droite avec  le message : 
 - Utilisateur connecté : toto@mail.com
