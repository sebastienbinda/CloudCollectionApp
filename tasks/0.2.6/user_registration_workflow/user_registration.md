Le  mail de validation d'un nouvel utilisateur par l'administrateur ne doit etre envoyé que apres que le user ai validé son adresse email si la validation par admin est active.

Apres avoir valider son email, le user est redirigé sur une page, cette page doit indiquer que son compte sera utilisable une fois que l'admin autra validé son email si la validation est active, sinon on le redirige directement sur la page de connexion.

Une fois que l'admin  a valider le compte de l'utilisateur et si la validation par admin est activé, alors un mail est envoyé a l'utilisateur l'informant que l'administration a validé son compte et qu'il peut désormais se connecter en lui donnant le lien vers la page de connexion.
