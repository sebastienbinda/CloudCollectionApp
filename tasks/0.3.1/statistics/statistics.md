En tant qu'utilisateur connecté je veux avoir accès à une nouvelle section "Statistiques" accesible depuis le menu qui permet d'afficher une page de statistiques sur ma collection.

Cette page affiche des diagrames permettant de visualiser : 
 - La proportions de jeux par plateformes dans la collection
 - La repartition temporelle sur la date de release des jeux de la collection
 - La repartition temporelle sur la date d'achat des jeux de la collection

La liste des jeux les mieux notés de la collection (note > 9) en présentant pour chaque jeu :
 - Le nom du jeu
 - La plateforme
 - La date de sortie
 - La date d'achat

L'entrée du menu est visible dans le menu desktop mais aussi dans le menu mobile avec une icone dédiée.

Cet écran doit avoir un rendu mobile spécifique pour afficher correctement ces différentes informations.

Il faut ensuite rajouter une page de documentation statistics.md qui explique de facon synthétique cet écran pour analyse par les agents IA lors des futures évolution et ajouter ce fichier comme les autres dans le fichier AGENTS.ms.
