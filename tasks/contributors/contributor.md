Ajouter l'indication de quel utilisateur a ajouter une entrée aux entités de la bibliothèque de jeux, studios ou plateforme. 

L'utilisateur peux configurer l'anonima et dans ce cas, seul son id est référencé Sinon un pseudo configurables par les utilisateurs est ajouté en base de données.

Cette configuration doit être porposée a la création du compte utilisateur.

Le nombre de contributeurs est ensuite affiché dans la section bibliothèque pour chaque type d'entité.
Le pseudo est affiché dans les tableau de listing ou anonyme si l'utilisateur ne veux pas etre identifié.

Idée suplémentaire : Ajouter un score de contributeur.
Chaque utilisateur a une page perso lui indiquant son score de contribution avec : 
 - Nombre de jeux ajouter a la base commune
 - Nombre de plateformes
 - Nombre de studio
 - Calcul d'un score affiché sous forme de Level pour avoir une ref aux jeux video. 
 - Le Level allant de 1 à 100 et étant calculé en fonction de la contribution a la base commune.
